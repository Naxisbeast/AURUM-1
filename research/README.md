# Research

This directory documents every strategy variant that has been researched, tested, and either promoted or rejected for AURUM.

```
promoted/    ← Strategies that earned their way into production
completed/   ← Research that produced meaningful findings but wasn't promoted
rejected/    ← Experiments that failed or were abandoned
```

The actual code for each variant lives in `scripts/shadow/`. This directory tells the story of what was learned from each one.
