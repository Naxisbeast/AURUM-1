# Rejected Experiments

This directory documents experiments that failed or were abandoned.

- ML ensemble (added no edge over simple rules)
- Market regime classifier (never produced actionable signals)
- Sentiment scoring (data quality too poor for M15 trading)
- Pullback-breakout state machine (produced ~3 trades/week)
- Multi-asset experiments (unfocused, stopped early)

Each one taught me something about what doesn't work.
