# D6 — Donchian 20, 2R Exit, BUY+SELL, ML Ensemble

**Status**: ✅ Completed — research only.

**What it tested**: Donchian 20 breakout with 2R exit, BUY+SELL, with ML ensemble (regime classifier + direction predictor).

**Result**: Profit factor 1.14 over 11 years — identical to D4. The ML ensemble added nothing measurable.

**Lesson**: This was the most important dead end. It proved that complexity doesn't justify itself. ML should only be added if it produces edge that simple rules can't. D6 proved it didn't.
