# D5 — Donchian 20, Adaptive ATR Exit, BUY+SELL

**Status**: ✅ Completed — research only.

**What it tested**: Donchian 20 breakout with an adaptive ATR-based exit instead of fixed 2R. BUY+SELL.

**Result**: Never reached production comparison. Adaptive exits introduced more complexity without clear evidence of improvement over fixed 2R.

**Lesson**: Fixed 2R is simple, testable, and well-understood. Adaptive exits need to prove they can outperform it consistently.
