# D1 — Original Forward Shadow (1R, BUY Only, Filtered)

**Status**: ✅ Completed — ran as the initial forward shadow candidate.

**What it tested**: Donchian 20 breakout with 1R take profit, BUY-only, with volatility and session filters.

**Result**: Weak performance. Too few trades due to filters. Superseded by later variants.

**Lesson**: Filters remove good trades alongside bad ones. D4 proved that no filters + 2R exit was the better path.
